# Dark Mode V2 — approved design

Approved on 7 October 2026.

## Visual rule

PesaTrack dark mode is charcoal-first. Emerald identifies PesaTrack and highlights
primary actions, positive states, selected controls and progress. It is no longer
the background color for most cards and pages.

## Core palette

- Background: #0D1412
- Surface: #151D1A
- Elevated: #1B2622
- Card / surface variant: #202C28
- Border: #2D3B36
- Primary text: #F4F7F5
- Secondary text: #AAB8B2
- Emerald: #23C483
- Mint: #8DE7BF
- Blue: #60A5FA
- Amber: #FBBF24
- Red: #F87171
- Purple: #A78BFA

## Usage

- Home and Accounts may keep one emerald hero because they represent the user's
  primary money position.
- Reports, bills, goals, activity summaries, settings, secondary cards and list
  items use neutral charcoal surfaces.
- Semantic color lives in icons, pills, progress, charts and status text.
- Bottom navigation is neutral charcoal with a subtle emerald selected state.
- Transaction details use a neutral summary card with category color as the
  accent.
- Light mode is intentionally not redesigned in this pass.

The goal is roughly 70% neutral charcoal surfaces, 20% elevated neutral layers
and 10% PesaTrack emerald / semantic color.
