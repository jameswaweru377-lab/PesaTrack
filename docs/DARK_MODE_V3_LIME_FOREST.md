# Dark Mode V3 — Lime / Forest Theme

Reference direction approved as a theme refinement after Dark Mode V2.

## Scope

This is a theme-only change. Existing screen layouts, cards, sections, information
architecture and navigation destinations remain unchanged.

The one allowed navigation styling change is a more prominent center Transactions
button inspired by the supplied banking reference.

## Palette

- Background: #07100A
- Surface: #0E190F
- Elevated surface: #1B2A1C
- Surface variant: #152217
- Outline: #2B3C2D
- Primary text: #F5F8F2
- Secondary text: #A9B6A7
- Primary lime: #C8F43D
- Bright lime: #E1FF72
- Supporting emerald: #25C98A
- Emerald container: #0E3024

## Theme rules

- Deep black/forest surfaces remain the dominant canvas.
- Lime is reserved for primary actions, selected navigation, key financial heroes
  and high-priority emphasis.
- Emerald remains the PesaTrack supporting brand/positive color.
- Semantic blue, amber, red and purple remain unchanged for meaning.
- Main financial hero components use the same layout and wallet artwork, but the
  dark-theme hero gradient becomes lime with dark foreground text.
- Light mode is not redesigned.
- The bottom navigation keeps all five destinations and routes. Transactions,
  already the center item, receives a raised circular treatment inspired by the
  supplied reference image.
